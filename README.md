# 制約

- とりあえず100MHz前提
- ポートは`src/<名前>/<名前>.sv`に書いてあるもので決まっている
- 入力ポートは組合せで来るので、入口のFFの前に回路を挟まない。出力は組合せで出す
- 出力の最終段(最後のFFから出力ポートまで)は(とりあえず)半サイクルで終わるようにする。set_output_delay 5ns
- validは持たない。データのFFにリセットは要らない

## fmul / fadd / itof / ftoi

- 毎サイクル新しい入力を受けられる、固定レイテンシのパイプラインにする
- 段数は決まっていない
- faddはaux=1でfsub
- itofの入力とftoiの出力は符号付き32bit。ftoiは最近接丸め(四捨五入)

## fdiv / fsqrt

- 非パイプラインのマルチサイクルでいい
- issued/done/abort_ffの約束はファイルの先頭のコメント参照
